# Your Move for Jira

**Every task. A clear next move.**

Keep Jira delivery ownership clear while making the next action visible, acknowledged, and traceable. Assignee owns delivery; each Ball identifies a specific next action and its holder. An issue can have several independent Balls.

- [Install and test Your Move](JUDGE-GUIDE.md)
- [Watch the English demo — 2:35](https://youtu.be/cnNutuTzSNE)
- [Privacy and data handling](PRIVACY.md)
- [Ask a support question](https://github.com/ducnmm/your-move-docs/issues/new)

Your Move runs on Atlassian Forge inside Jira Cloud. No AI provider, model token, external integration, or shared credentials are needed. Email is optional and defaults to Off.

This is an evaluation release, not an Atlassian Marketplace listing. Application source is maintained separately. The installation guide documents setup, verified behavior, and known limits.
